# Аттестация 1103

Тренажёр для тех, кто готовится к аттестационному тестированию на должность руководителя московской школы. Тест идёт по пяти модулям: кадры, ресурсы, процессы, результаты, информация. Чтобы пройти, нужно набрать не меньше 70% в целом и не меньше 50% по каждому модулю.

Программа работает на компьютере без интернета. Сеть нужна только для обновлений.

> Сейчас в программе пробная база: по пять заданий на модуль, один кейс и десять карточек. На ней можно попробовать все режимы. Полная база, около трёхсот заданий, придёт обновлениями по модулям, переустанавливать ничего не придётся. Полный экзамен и прогноз готовности откроются, когда будут готовы все пять модулей.

## Первый запуск на Mac

У программы нет платной подписи Apple, поэтому macOS в первый раз её не откроет. Это ожидаемо, разрешить нужно один раз.

1. Откройте скачанный `.dmg` и перетащите программу в папку «Программы».
2. Запустите её. Появится сообщение, что программу не удалось проверить. Нажмите «Готово».
3. Откройте «Системные настройки» → «Конфиденциальность и безопасность» и прокрутите вниз до раздела «Безопасность».
4. Рядом со строкой про Attestat1103 нажмите «Всё равно открыть» и подтвердите паролем или отпечатком.

Дальше программа открывается как обычная.

Если вместо этого macOS пишет, что программа повреждена, откройте «Терминал» и выполните:

```bash
xattr -dr com.apple.quarantine /Applications/Attestat1103.app
```

## Первый запуск на Windows

Браузер может предупредить, что файл скачивают редко. В Edge нажмите «…» рядом с загрузкой, затем «Сохранить» и «Всё равно сохранить».

Запустите установщик. Windows покажет синее окно «Система Windows защитила ваш компьютер». Нажмите «Подробнее», затем «Выполнить в любом случае».

Сборку для Windows делает GitHub, на настоящем компьютере с Windows её пока никто не запускал. Если что-то не работает, [напишите об этом](https://github.com/SOJuse/attestat-trainer/issues/new).

## Как заниматься

**Сегодня.** Ежедневная сессия: сначала задания, которые пора повторить, потом новые. После первого ответа задание вернётся завтра. Дальше каждый верный ответ отодвигает его: на 3 дня, потом на 7, 16 и 35. Ошиблись, и оно снова вернётся завтра. Размер сессии меняется в настройках, от 5 до 50 заданий. Если закрыть программу посреди сессии, она продолжится с того же места.

**Тренировка.** Задания по выбору: модуль, тема, сложность, тип, только те, где была ошибка. Здесь же кейсы: одна ситуация и несколько шагов, перед каждым шагом условия меняются.

После ответа программа показывает разбор: почему верен или неверен каждый вариант, дословную цитату нормы и ссылку на это место в библиотеке. Если в задании ошибка, нажмите «Сообщить об ошибке» под разбором. Задание можно скрыть, оно больше не попадётся.

**Экзамен.** Режим «как в аудитории»: 40 заданий на 60 минут, по 8 на модуль, разбор только в конце. Зачёт: не меньше 70% в целом и не меньше 50% по каждому модулю. Число заданий и время взяты условно, официальные документы их не называют. Библиотеку во время теста открыть можно, как и на настоящем тестировании. Пока база пробная, доступны мини-тесты по одному модулю.

**Карточки.** Сроки, доли и числа из норм. Вспомнили ответ, открыли, отметили «знаю» или «не знаю».

**Прогресс.** Точность по каждой теме и история экзаменов. Тема, где верных ответов меньше 60%, помечена как слабая, рядом кнопка «Тренировать».

## Перенос на другой компьютер

Прогресс хранится только на вашем компьютере. Чтобы перенести его, откройте «Настройки», нажмите «Сохранить прогресс в файл», а на другом компьютере «Загрузить прогресс из файла». Там же прогресс можно сбросить.

## Библиотека

В разделе «Библиотека» лежат тексты документов из списка литературы для подготовки к тестированию. У каждого документа указано, откуда он взят, какая это редакция и когда текст скачан.

Тексты бывают трёх видов:

- Законы, кодексы, указы и постановления Правительства взяты с официального портала правовой информации в действующих редакциях.
- Приказы министерств и санитарные правила распознаны программой со сканов официальной публикации. В таком тексте могут быть ошибки, чаще всего в числах и номерах пунктов, поэтому над ним стоит предупреждение, а рядом кнопка «Открыть источник». Это текст на дату принятия документа: позднейшие изменения в него не внесены, изменившие акты перечислены над текстом.
- Часть документов пока стоит без текста. Это московские акты, приказы Департамента образования и письма министерств: в открытых официальных источниках их получить не удалось.

При первом открытии раздела программа предложит скачать библиотеку, это несколько мегабайт. Дальше она работает без интернета и сама подтягивает обновления при запуске.

Поиск понимает формы слова: по запросу «отпуск по уходу» найдётся и «отпуском по уходу», и «отпуска по уходу». Однокоренные слова другой части речи он не сводит: «увольнение» не найдёт «уволить».

## Обновления

При запуске программа сама проверяет, вышла ли новая версия. Если вышла, вверху окна появится строка с кнопкой «Обновить». Программа скачает обновление и перезапустится. Проверить вручную можно в настройках.

Без интернета программа просто открывается и работает на том, что уже скачано.

## Важно

Тренажёр неофициальный. Он не связан с Корпоративным университетом московского образования и Департаментом образования и науки города Москвы. Задания авторские, из экзаменационного банка они не взяты.

## Для разработчиков

Нужны Node.js 24 и Rust.

```bash
cd app
npm ci
npm run tauri dev
```

Проверки: `npm run lint`, `npm run typecheck`, `npm test`, дымовой тест в браузере `npm run e2e`. Интерфейс запускается и в обычном браузере: `npm run dev`, затем `http://localhost:1420`.

Релиз собирается сам, когда в репозиторий приходит тег вида `v0.3.0`. Перед этим ту же версию нужно записать в `app/package.json`, `app/src-tauri/tauri.conf.json` и `app/src-tauri/Cargo.toml`.

Задания лежат в `content/tasks`, кейсы в `content/cases`, карточки в `content/cards`. Каждое задание ссылается на норму дословной цитатой, `npm run validate` в `tools` проверяет, что цитата есть в тексте документа. Как пишутся и проверяются задания, описано в `tools/prompts`.

Как устроен проект и что запланировано, описано в [docs/superpowers/specs](docs/superpowers/specs).
