# Поручение: сверить тексты корпуса с источником

Ты проверяешь, что тексты актов в `content/docs/<id>/text.md` совпадают с тем, что отдаёт
официальный портал `actual.pravo.gov.ru`, и что при разборе ничего не потеряно и не перепутано.
Ничего не исправляй и не коммить: только отчёт.

Как получить текст с портала: `tools/fetch/ips.py` (прочитай его начало). Из Python:

    import sys; sys.path.insert(0, 'tools/fetch'); import ips
    doc = ips.search(number, date)[0]
    red = ips.actual_redaction(doc['dochash'])
    html = ips.api(f"redtext?bpa=ebpi&t={red['redid']}&ttl={ips.TTL}")['redtext']

Запускать: `tools/fetch/.venv/bin/python`. Между запросами скрипт сам делает паузу.

Для каждого документа из списка, который тебе дали:

1. Сравни дату редакции в `meta.yaml` (`edition`) с актуальной редакцией на портале.
2. Возьми указанное число разделов из разных мест документа: начало, середина, конец, плюс
   статьи с дробным номером (11.1, 60.2), если они есть. Для каждого найди этот же фрагмент
   в HTML портала и сравни текст дословно, не обращая внимания на пробелы и переносы.
3. Проверь, что заголовок раздела в `text.md` тот же, что на портале, и что якорь соответствует
   номеру (`Статья 60.2` → `st-60-2`).
4. Посчитай статьи в HTML (`<p class="H">Статья N…`) и разделы `st-*` в `text.md`. Расхождение
   объясни: какие статьи пропали или склеились.
5. Посмотри на разделы с суффиксом `-dup`: что это за повторы на самом деле.

В отчёте по каждому документу: совпало или нет, и конкретные расхождения с цитатой
из обоих источников. В конце общий вывод: есть ли систематическая ошибка разбора.
Не пересказывай содержание актов и не добавляй в отчёт ничего по памяти.
