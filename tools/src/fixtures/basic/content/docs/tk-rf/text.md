## {#st-256} Статья 256. Отпуска по уходу за ребёнком

> ЧАСТЬ ЧЕТВЕРТАЯ / Глава 41. ОСОБЕННОСТИ РЕГУЛИРОВАНИЯ ТРУДА ЖЕНЩИН

По заявлению женщины ей предоставляется отпуск по уходу за ребенком. Женщина может выйти на работу, пользуясь отпуском частично.
